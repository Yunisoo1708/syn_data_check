# scripts/ - one-off probes and helpers

`misc/` holds small scripts written while debugging: `_enc_probe.py`, `_names_probe.py`, `_leak_probe.py` (check that no test complex leaks into training), `list_arch.py`, `list_layers.py` (print the network layers), and shell helpers for the GPU box (`_gpu_sample.sh`, `_nc_test.sh`, `_restart_real.sh`, `_stop_F_box.sh`, `run.sh`). None is part of the main workflow.
