# Figures

Every test of this project has a figure (a method strip showing what was done + the result chart). The image files are in this folder; the Python script that draws each one is in `scripts/` (run it with Python 3 and matplotlib; the scripts read result tables from `gen_test/`, `denoiser_trial/` and `data/`).

The section titles refer to `../Results.MD`, the full lab notebook. Figures 59 to 63 are the most recent (decoder bond and clash losses, refolding, clash loss in the denoiser).
